 <div id="banner">

  <div id="banner2">
    <div id="bannertext2" style="font-family: Tahoma, Geneva";>

<h1>&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;
&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;</h1>
<div id="limittext4">
<div id="indenttext">
The Lunar Dust Experiment (LDEX) is an impact ionization dust detector. It measures the mass
of individual dust grains with m &ge; 1.7x10<sup>-16</sup>kg (radius, r<sub>s</sub> &ge; 0.3 &mu;m) for impact speeds &asymp; 1.7 km/s and also measures the collective current due to grains below the threshold for individual detection, enabling the search for dust grains with radius r<sub>g</sub> &asymp; 0.1 &mu;m over the terminators. LDEX is either <b>ON</b> or <b>OFF</b> - No other operational modes.
</div>
<br>
<big><b>Useful Mission Documents</b></big><br>
<div id="indenttext">
<b><u><a href="https://sbnarchive.psi.edu/pds4/ldex/ladee_ldex_20161118/document/ladee_mission_rev1_5.pdf">Mission Description</a></u></b><br>
<br>
<u><b><a href="https://sbnarchive.psi.edu/pds4/ldex/ladee_ldex_20161118/document/ladee_spacecraft_rev1_2.pdf">Spacecraft Description</a></b></u>
</b><br><br>
<b><u><a href="https://sbnarchive.psi.edu/pds4/ldex/ladee_ldex_20161118/document/ldex_pds_sis_reve.pdf">Instrument and Data Description</a></u> - Software Interface Specification (SIS)</b>

<br><br>
</div>
<br>
<big><b>Archive Bundle Contents (Housed at the Small Bodies/Dust Node)</big></b><br>
<div id="indenttext">
<b><u><a href="https://sbnarchive.psi.edu/pds4/ldex/ladee_ldex_20161118/document/">Document</a></u></b> - Directory containing the document collection, which includes refereces to refereed
journals using this instrument, and information about calibration and explanation of data structures.<br>
<br>
<b><u><a href="https://sbnarchive.psi.edu/pds4/ldex/ladee_ldex_20161118/data_housekeeping/">Housekeeping Data</a></u></b> - Directory containing housekeeping data for the instrument.<br>
<br>
<b><u><a href="https://sbnarchive.psi.edu/pds4/ldex/ladee_ldex_20161118/data_reduced/">Reduced Data</a></u></b> - Directory containing processed data files.
<br><br>
<b><u><a href="https://sbnarchive.psi.edu/pds4/ldex/ladee_ldex_20161118/data_calibrated/">Calibrated Data</a></u></b> - Directory containing the calibrated data files.
<b>
Calibration Documentation is in the <a href="https://sbnarchive.psi.edu/pds4/ldex/ladee_ldex_20161118/document/ldex_pds_sis_reve.pdf">SIS</b></a>.
<br><br>
<b><u><a href="https://sbnarchive.psi.edu/pds4/ldex/ladee_ldex_20161118/data_derived/">Derived Data</a></u></b> – Directory containing derived values of dust density in the lunar atmosphere for grains with radii greater than 0.3 microns. The data consists of an ASCII table with dust density and errors  tabulated as a function of altitude every 1.5 hours from 19:30 through 0:00 to 10:30 local time. See Horyani, M., Z. et al., The Lunar Dust Experiment (LDEX) onboard the Lunar Atmosphere and Dust Environment Explorer (LADEE) Mission, Space Science Reviews, 185 104), 93-113, doi:10.1007/s11214-014-0118-7, 2014.
</div>
